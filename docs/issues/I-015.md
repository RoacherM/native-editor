# I-015 保存安全

2026-11-12 代码审查发现，第 1、2 条已对照源码核实。

| # | 缺陷 | 证据 |
|---|---|---|
| 1 | 图片、PDF、音视频、二进制（含被判成 binary 的 UTF-16 文本）Tab 按 `⌘S`、点菜单 Save 或在命令面板选 Save，原文件会被写成 0 字节 | `loadFile`：`const text = isOpaqueFile(classification) ? "" : decodeText(bytes)`；`saveFileInMap` 不检查类型和 `dirty`，直接 `saveFileText(file, file.text, root)` → `fs.writeFile` |
| 2 | 非 UTF-8 文件（GBK、Latin-1）不改内容、只按 `⌘S` 也会被永久改写成 U+FFFD；UTF-8 BOM 保存后丢失 | `decodeText` 用的是 `TextDecoder("utf-8", { fatal: false })`；保存不看 `dirty` |
| 3 | 命令面板的 `Switch to Source Mode` / `Switch to Diff Mode` 对图片、二进制也生效：出现可编辑的空编辑器，打字后 `⌘S` 会覆盖原文件 | `COMMAND_HANDLERS["mode-source"]` → `handleModeChange`，不检查类型 |
| 4 | `await` 保存（或切 Diff 模式）期间继续输入的内容会被旧副本覆盖，`dirty` 被错误清零；期间关掉的 Tab 会作为孤儿条目写回 `loadedFiles` | `saveFileInMap`、`updateFileModeInMap` 在 `await` 之后用旧 `file` 构造新值 |
| 5 | 保存失败（工作区外路径不在 `capabilities.fs.write` 里、只读文件、权限不足）没有任何提示，变成未处理的 rejection；未保存确认框里保存失败也不提示 | `saveFileInMap` 没有 try/catch，`withCurrent` 丢掉了 promise |
| 6 | 编辑 SVG 并保存后，预览仍显示旧图（重开也一样，因为预热缓存里存的是旧副本） | `saveFileText` 用 `...file` 展开，不重建 `blobUrl` / `dimensions` |
| 7 | 保存后 Diff 视图不更新 | `resolveModeFile` 只在 `!file.diffPatch` 时拉取补丁，保存后旧补丁还留着 |
| 8 | 未保存确认框的文案永远是「before closing?」，切换文件夹时也这么写 | App.tsx 确认框 |

## 期望

- 不透明类型（`isOpaqueFile`）永远不能保存，也不能切到 source 或 diff 模式；保存只在 `dirty` 时写盘。
- 解码用 `fatal: true`。失败时以只读打开，并在编辑区上方显示横幅（例如 `Not UTF-8 — opened read-only`），不能保存回去。记住 BOM，保存时写回。
- 保存完成后，与写入时的文本做比较：期间又改过的保持 `dirty`，并保留最新文本；已关闭的 Tab 不再写回。
- 保存失败时在编辑区显示错误横幅（说明原因和路径），Tab 保持 `dirty`。
- 保存后重建 SVG 的 `blobUrl`，清掉 `diffPatch`（下次进入 Diff 时重新拉取）。
- 确认框文案按动作区分（关 Tab / 关文件夹 / 切换文件夹）。

## verify

`nsh check && nsh test --trace`。先在 `App.test.tsx` 跑出 Red：

- `saving an image, binary or PDF tab never writes to it`（保存前后字节长度相同）
- `a file that is not UTF-8 opens read-only and is never rewritten`（含字节 `0xE9` 的样本，保存后字节完全相同）
- `a UTF-8 BOM survives a save`
- `source and diff modes are not offered for opaque files`
- `typing while a save is in flight stays dirty with the newest text`
- `a failed save says so and keeps the tab dirty`
- `a saved SVG shows its new picture`；`the diff view follows a save`
