# I-017 状态竞态与静默失败

| # | 缺陷 | 证据 |
|---|---|---|
| 1 | 用 `AED_ROOT` 启动（`aed dir`、把目录拖到图标上）会清空 Recent，只剩当前一项（已核实） | 启动时 `recordRecentWorkspace(recentWorkspaces, initialRoot)` 在 `initUserPreferences` 读入已存列表之前执行，信号还是 `[]`，随即 `Storage.setItem` |
| 2 | 旧目录的慢扫描完成后覆盖新目录的文件树、Git 徽章、`⌘P` 列表和分支 | `refresh`：`const scanned = await scanWorkspace(workspaceRoot()); snapshot.set(scanned)`，不检查根目录是否仍是当前这个；初始扫描同理 |
| 3 | 快速切换两个 `.mmd` Tab 时，慢的旧渲染结果覆盖新的；换代码时旧图一直挂着，没有加载态 | `MermaidDiagramBlock` 的 effect：`requestMermaidRender(...).then(res => rendered.set(res))`，没有序号保护 |
| 4 | Changed 列表里已删除（`D`）的文件点了没反应，看不到它的 diff；外部打开失败也静默，而且 `click-file` 打开失败前文件树已被清掉 | `openFileInTab` → `loadFile` → `fs.readFile` 抛错，没人接；`openExternalFile` 先 `clearWorkspaceTree()` 再打开 |
| 5 | Markdown 里指向不存在文件的链接，点了没反应 | `openFileInTab` 没有 await，也没有 catch |
| 6 | `⌘0` 除了重置字号，还把字体也重置了 | `resetFont` 调用 `setFontFamily(DEFAULT_FONT_FAMILY)` |
| 7 | 查找栏是整个 PreviewPane 共用的：切到预览类 Tab 后 `⌘F` 关不掉；在终端里按 `⌘F` 也会打开编辑器的查找栏；Esc 不关闭 | `findOpen` 在 PreviewPane 层；`⌘F` 只在 `getActiveView === "editor"` 时切换 |
| 8 | 一次拖入多个文件只打开第一个 | `decodeDroppedUri(uris[0])` |
| 9 | CSV 引号里的换行会把表格拆乱；数字检测不 trim、`007` 被当成 7、混合列排序不稳定、上一个 CSV 的排序带到下一个；JSONL 坏行静默丢弃 | `classify.ts` `parseTableData` / `splitLines`；`PreviewPane.tsx` `tableSort` |
| 10 | 文件不设大小上限：GB 级未知二进制整个读进内存，只为显示 4 KB Hex；PDF 和 Office 也整读 | `readFileBytesAndSize` → `fs.readFile` |
| 11 | `serialize`：任务抛错后 `again` 一直为 true，排队的重跑被跳过 | `src/session.ts` |

## 期望

每条一个 Red 测试，再最小修复。大文件策略：未知或二进制只读前 4 KB；文本超过一个上限（比如 8 MB）时只读并提示，不进编辑器。具体上限写进 `DESIGN.md`。
