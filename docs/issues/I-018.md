# I-018 `/tmp` 安全、外部打开与权限收窄

| # | 缺陷 | 证据 |
|---|---|---|
| 1 | `/tmp/aed-open.queue` 是全局可写目录里的固定路径，而且会跟随符号链接：其他本机用户可以预先建一个指向受害文件的链接（Aed 追加后再截断成 0 字节），或者往里写路径让 Aed 打开 | `finder_bridge.m` `fopen("/tmp/aed-open.queue", "a")`；`workspace.ts` 读完后 `fs.writeFile(QUEUE, "")` |
| 2 | `/tmp/aed-mermaid/mermaid-docu-bundle.js` 只检查 `length > 1000` 就作为 JS 注入 Mermaid WebView（`webview.hosts: *`） | `mermaid.tsx` `loadMermaidBundleJs` |
| 3 | 所有 Aed 进程共用同一个队列，条目会被别的实例抢走，或者残留到下次启动才打开；读和截断不是原子操作 | `consumeFinderOpenQueue` |
| 4 | 文件名本身带 `:数字` 或 `#L数字` 的，会被当成行号截掉（launcher 已经用 `realpath` 找到了真实文件，之后又被剥一次）；剥出来的行号也从来没用来跳转 | `normalizeExternalFilePath` 的正则 |
| 5 | 命令行 `file://` 参数不做百分号解码（`My%20Notes.md`、`file://localhost/...`）；多个文件参数只取最后一个 | `launcher.c` |
| 6 | Finder 里选 N 个文件打开会起 N 个独立进程 | `finder_bridge.m` 对每个文件都 `open -n` |
| 7 | `/tmp/aed-ql` 的 PDF 预览图从不清理；`blob:` URL 从不 `revokeObjectURL` | `classify.ts` `quickLookCache`、`mermaid.tsx` `renderCache` |
| 8 | `nsh.json` 授权 `network.hosts: *` 和 `webview.hosts: *`，对一个声明没有网络后端的 App 来说过宽；`.html` 预览没有 CSP，页面 JS 直接运行；单独的 `.mmd` 渲染用 `securityLevel: "loose"` | `nsh.json`、`PreviewPane.tsx` WebView、`mermaid.tsx` |
| 9 | Info.plist 把 `public.data` 注册为 Default，等于声明能编辑所有文件类型；首次安装会自动接管系统默认的文本编辑器，不问用户 | `scripts/package-macos.sh` |

## 期望

- 临时文件改放到每个用户自己的目录（`$TMPDIR`，或 `~/Library/Caches/dev.byronwayne.aed/`），创建时用 `O_NOFOLLOW | O_EXCL`、权限 `0600`。旧的 `/tmp/aed-*` 路径不再读取。迁移和兼容写进 `DESIGN.md「术语与边界」`（AGENTS.md 第 2 条）。
- 队列改成每个进程各用一个（或者 launcher 只用 `AED_OPEN_FILE` 传路径，不经过共享文件）。
- 先试 `realpath` 原路径，存在就不剥 `:line`；剥出的行列真正用来跳转。
- 改 `nsh.json` 权限、`scripts/` 原生代码，按 AGENTS.md 第 6 条交给另一个模型独立审查 `git diff`。
