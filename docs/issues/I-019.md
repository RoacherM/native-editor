# I-019 真正的 TTY 终端

现在的终端是一个单行 `<Input>`，按 Enter 才把整行写进 PTY（`TerminalPane.tsx` `onSubmit` → `writeCommandToSession`）。所以：

- 没有 Ctrl-C、Ctrl-D、Tab 补全、方向键历史、Esc 序列：`sleep`、`tail -f`、`npm run dev` 一跑就卡死，只能关 Tab；
- 只认 CSI D/C/G/K/J，颜色（SGR）、光标定位、备用屏（`?1049h`）、滚动区域都被丢掉，`vim`、`less`、`top`、`htop` 都不能用，进度条会重复或乱码，却对外声明 `TERM=xterm-256color`；
- PTY 尺寸写死 32×140，不跟随面板大小（没有 `TIOCSWINSZ` 更新 / `SIGWINCH`）；
- 输入 sudo 密码时，内容在输入框里明文可见；
- 有输出就滚到底，没法往回翻；1000 行上限加上 `key="index"`，到上限后每个 chunk 都要重绘全部行；
- 切换 Shell（偏好设置或下拉框）会直接杀掉正在跑任务的会话，不确认。

## 方案（用户已拍板：要做成真正的 TTY）

照 Markdown 预览的先例（I-013）：**WebView + 固定版本的 xterm.js**。

- `vendor/xterm/`：`package.json` + `bun.lock` 锁定 `@xterm/xterm` 以及 `@xterm/addon-fit`、`addon-web-links`、`addon-unicode11`（按需）。由 `scripts/build-xterm-vendor.sh` 构建为 `src/xtermVendor.generated.ts`（JS + CSS 字符串，带 buildId 防漂移），生成物不手改。许可证写进 `THIRD_PARTY_NOTICES.txt`。
- 页面壳层：严格 CSP，0 个 `<script>`，运行时在 `onLoad` 用 `injectJavaScript` 注入（沿用 DESIGN 踩坑 #10 的结论）。主题（`theme.ui` → xterm `ITheme` 加 16 色 ANSI 调色板）、字体、字号从偏好设置传进去，改了就热更新。
- PTY 桥（`python3 pty.fork()`）改成有帧格式的双向协议：
  - stdin：每行一条命令，`D<base64>` 是输入字节，`R<rows> <cols>` 是 resize（`TIOCSWINSZ` 后 shell 自然收到 `SIGWINCH`）；
  - stdout：每行一条 `O<base64>`，避免 UTF-8 在 chunk 边界被切断；页面端解码成 `Uint8Array` 再 `term.write`；
  - 子进程退出时发一条带退出码的消息。
- 页面上行消息：`ready`、`input`（`term.onData`）、`resize`（fit addon 算出的 cols/rows）、`title`（OSC 0/2，可用于终端 Tab 名）、`link`（经 `openUrl` 打开）。纯协议、校验和编解码放进 `src/terminalPage.ts`（无 I/O，可单测）；`TerminalPane.tsx` 只做 I/O 外壳。
- 键盘：WebView 拿到焦点后，Ctrl-C、Tab、方向键、Esc 交给 xterm；App 的 `⌘` 快捷键仍然有效。终端获得焦点时 `⌘K` 改为清屏（而不是快速打开），`⌘F` 不再打开编辑器的查找栏。复制粘贴走 xterm 的选区和剪贴板。
- 多终端 Tab：每个 Tab 一个 xterm 实例（同一个 WebView 内切换，或每个 Tab 一个 WebView，取实测更稳的那种），切 Tab 保留滚动记录；输出在宿主侧缓冲，页面 ready 之前的输出 ready 后补发。
- 保留现有行为：面板第一次显示才启动 Shell、未输入过的 Shell 跟随目录（`shouldFollowCwd`）、启动中输入排队（`createInputGate`）、Ghostty 配置探测、Shell 下拉。「是否输入过」改为由 `input` 消息判定。
- 切换 Shell 时，用过的会话不再被杀掉；新 Shell 只用于新 Tab 和未使用的会话。

## 测试

- 无头 `nsh test` 不执行 WebView 页面 JS（DESIGN 踩坑 #10），所以：
  - `src/terminalPage.ts` 的帧编解码、消息校验、主题映射写纯单测；
  - PTY 桥用真实 `python3` 测：写入 `D` 帧能执行命令、`R` 帧之后 `stty size` 报出新尺寸、Ctrl-C（`\x03`）能中断 `sleep 30`、UTF-8 中文跨帧不乱码；
  - 加一个**仅测试用**的宿主事件通道（类似 `aed.preview.eval`），让测试能向当前终端会话写字节，并读到去掉 ANSI 后的输出文本。**`App.test.tsx` 里 `runInTerminal(app, cmd, marker)` 必须保持同样的签名和语义**：别的测试（`withScratch`、磁盘冲突等）都用它写文件。
- 页面行为（键盘、渲染、resize）只能用 `--target macos` 真机验证，那会占用用户的鼠标键盘，跑之前先问用户。
