# I-014 文件树与 Tab 不感知外部改动

在 Finder、终端或别的编辑器里改名、删除、新建文件或目录，Aed 的文件树一直显示旧的样子。已经打开的 Tab 指向一个不存在的路径，却没有任何提示，这时保存会在旧路径把文件重新建出来。

## 复现（`nsh 0.4.0`，无头 `nsh test`，2026-11-12 实测）

1. 工作区里放 `old-name/a.txt`，用 `host.params.workspaceRoot` 打开。
2. 展开 `old-name`，打开 `a.txt`。
3. 在内置终端里执行 `mv old-name new-name`。
4. 等 4 秒，再 `setLifecycle("inactive")` → `setLifecycle("active")`，等 1 秒。

实际结果：

```text
after 4s     old: true  new: false
after focus  old: true  new: false
tab still shows a.txt: true
```

期望结果：文件树里出现 `new-name`，`old-name` 消失；`a.txt` 的 Tab 跟到新路径，或者明确提示文件已被移走。

复现脚本：`.scratch/review/review.test.tsx`（`.scratch/` 不入库，修复时改写进 `App.test.tsx`）。

## 修复建议

- **刷新时机**：`lifecycle()` 变成 `active` 时刷新一次。`active` 期间每约 2 秒 `stat` 一遍工作区根目录和**已展开目录**的 `mtimeMs`（子项增删改名会改变目录的 mtime），只重扫变了的子树，同时重跑 `git status`。比对不能重叠，用 `serialize`。
- **改名迁移**：同一父目录下一个条目消失、同时新增一个同类型条目时，按改名处理，把 `expandedIds`、`selectedPath`、`openTabs` 和 `loadedFiles` 里这个路径前缀下的 key 都迁到新路径。
- **源文件消失**：把「读不到戳」当成一种单独的状态（已移走），不能当成「没变」。编辑区上方显示横幅：`File moved or deleted` + `Save As…` / `Close`。保存时不能静默在旧路径重建。
- **根目录消失**：回到 `WelcomePanel` 或显示明确的提示，不能继续显示旧文件树。
- **读取失败**：`scanDirectory` 读失败时把目录标成「无法读取」，不要返回 `[]`；先过滤再截断，被截断的目录末尾显示一行 `N more items not shown`。
- **无障碍名称**：给所有只有图标的按钮加 `accessibilityLabel`，图标意义不明的加 `tooltip`。

不涉及 `Storage` 键、`AED_*` 环境变量或 `/tmp/aed-*` 路径。在 `DESIGN.md「状态机清单」`新增「工作区与磁盘一致性」一行（与 #3「文件与磁盘一致性」并列），写清刷新时机与轮询间隔常量。
